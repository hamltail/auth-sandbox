# Auth Sandbox

認証ライブラリ選定用リポジトリです。

このプロジェクトは、自作認証を実装した
[`nextjs-sandbox`](https://github.com/hamltail/nextjs-sandbox)
をベースに派生し、Better Auth および Auth.js の検証を行います。

## Comparison Targets

- Better Auth
- Auth.js

## Tech Stack

- Next.js
- React
- TypeScript
- Prisma
- PostgreSQL
